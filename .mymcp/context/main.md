# Main Context

## Goal

Desenvolver software com regras duráveis, contexto centralizado e entregas guiadas por spec.

## Rules

- Mantenha este arquivo curto e estável.
- Atualize este contexto quando uma regra de arquitetura, domínio ou processo precisar permanecer válida por vários ciclos.
- Prefira mudanças guiadas por spec em vez de alterações ad hoc.

## Constraints

- O MCP deve operar apenas dentro do workspace.
- Artefatos de feature e tarefa devem viver em `.mymcp/specs`.
- Escrita livre continua disponível, mas o fluxo preferencial é via ferramentas de spec.

## Notes

- Use este arquivo como entrada principal para orientar novas features e tarefas.
